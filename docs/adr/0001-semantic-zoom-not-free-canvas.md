# Semantic zoom instead of a free pan/zoom canvas

The cheat sheet is meant to "work like a map", but what Students actually need is the Overview plus fast navigation. We use semantic zoom (Overview of tiles → animated zoom into a normal, scrollable page with a way back out) rather than an infinite pan/zoom canvas, because a free canvas breaks Ctrl+F, makes code unreadable mid-zoom, is awkward on trackpads/phones, and makes every content addition a layout problem.
